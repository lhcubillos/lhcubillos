## What I'm working on

[Phantom Neuro](https://www.phantomneuro.com) is building an implantable EMG device for improving prosthetic control. I work on making that control more reliable and usable in the real world.

Before this I did a PhD in Robotics at the University of Michigan ([Chestek Lab](https://chestekresearch.engin.umich.edu/)), on brain-machine interfaces and implanted EMG for prosthetic control.
